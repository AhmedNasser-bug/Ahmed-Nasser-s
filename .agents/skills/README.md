## 📂 Category Breakdowns

### 1. 🎨 Frontend Design & User Experience (UX)

When building pages, components, or entire frontends, use these skills to guarantee exceptional visual polish, structural integrity, and inclusive accessibility.

* **[frontend-design](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/frontend-design/SKILL.md):** Guides the aesthetic choices. It defines principles for choosing unique typography, color palettes, motion dynamics, layout asymmetry, and texture overlays. It enforces avoiding "generic AI templates."
* **[accessibility](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/accessibility/SKILL.md):** Enforces WCAG 2.2 accessibility principles (Perceivable, Operable, Understandable, Robust). It outlines code-level requirements for target sizes (24px/44px), keyboard navigation, focus management, screen readers, forms, and dynamic live regions.
* **[seo](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/seo/SKILL.md):** Provides structure for search engines. It covers meta description optimizations, semantic tags, heading hierarchies, structural data (JSON-LD schemas), and performance requirements to maximize page indexability.

### 3. 🌐 Three.js & Interactive 3D Graphics (The 3D Suite)

The Three.js suite is highly modular. Choosing the right skill depends on which aspect of 3D rendering you are currently working on.

> [!TIP]
> **How to combine 3D skills:** A complex 3D project will often require referencing multiple sub-skills. For example:
> * Setting up a new scene? Use **[threejs-fundamentals](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-fundamentals/SKILL.md)**.
> * Loading a custom model? Use **[threejs-loaders](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-loaders/SKILL.md)**.
> * Animating the model? Use **[threejs-animation](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-animation/SKILL.md)**.
> * Adding mouse clicks to select nodes? Use **[threejs-interaction](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-interaction/SKILL.md)**.

* **[threejs-fundamentals](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-fundamentals/SKILL.md):** Standard scene, cameras, render loop, resize handlers, and scene graph coordination.
* **[threejs-geometry](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-geometry/SKILL.md):** Built-in primitives vs. `BufferGeometry`, custom attribute creation, index arrays, and instanced meshes for heavy performance scaling.
* **[threejs-materials](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-materials/SKILL.md):** Configuration of PBR materials (Standard, Physical, Phong, Basic) and standard shader hooks.
* **[threejs-textures](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-textures/SKILL.md):** UV coordinates, normal maps, roughness maps, displacement mapping, mipmapping, and texture filtering optimization.
* **[threejs-lighting](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-lighting/SKILL.md):** Shadows, light types (Directional, Point, Ambient, Spot), and setting up high-performance Image-Based Lighting (IBL).
* **[threejs-loaders](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-loaders/SKILL.md):** GLTF/GLB models, custom texture formats, loading screen management, and async loading patterns.
* **[threejs-animation](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-animation/SKILL.md):** Animation mixers, skeletal rig clips, morph targets, keyframe generation, and smooth blending interpolation.
* **[threejs-interaction](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-interaction/SKILL.md):** Raycasting implementation, custom bounding boxes, orbit controllers, and handling user pointer events in a 3D context.
* **[threejs-postprocessing](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-postprocessing/SKILL.md):** Effect composers, passes (Bloom, Bokeh, DOF, Outline), render targets, and custom full-screen shader filters.
* **[threejs-shaders](file:///d:/Study/Programming/Projects/Portfolio%203/Ahmed-Nasser-s/.agents/skills/threejs-shaders/SKILL.md):** Writing custom vertex and fragment shaders using GLSL, mapping custom uniforms/attributes, and animating procedural effects.
