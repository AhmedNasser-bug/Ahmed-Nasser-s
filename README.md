# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Elements**: Engaging user interactions powered by JavaScript
- **Optimized Stylesheets**: Includes both full and minified CSS versions

## Project Structure

```
├── index.html          # Main landing page
├── about.html          # About page
├── style.css           # Main stylesheet
├── blueprint.css       # Additional styling framework
├── generated-tailwind.css  # Tailwind CSS styles
├── animations.js       # Animation scripts
├── shared.js           # Shared JavaScript utilities
├── about.js            # About page specific scripts
└── update_shared.js    # Utility for updating shared components
```

## Technologies Used

- HTML5
- CSS3 (including Tailwind CSS)
- JavaScript (ES6+)
- Blueprint CSS Framework

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. No build process required - ready to use!

## Customization

- Edit `style.css` or `blueprint.css` to modify the visual design
- Update content in `index.html` and `about.html`
- Modify JavaScript behavior in the respective `.js` files
