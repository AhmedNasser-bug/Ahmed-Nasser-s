🔒 [Security Fix] Pin Tailwind CSS CDN link and add Subresource Integrity (SRI)

🎯 **What:**
- Pinned the Tailwind CSS CDN link from `https://cdn.tailwindcss.com` to version `3.4.5`.
- Added the `integrity` attribute containing the SHA-384 hash of the file.
- Added the `crossorigin="anonymous"` attribute to the script tag in `index.html`.

⚠️ **Risk:**
- Unpinned CDN links without SRI expose the site to arbitrary code execution if the CDN is compromised, leading to Cross-Site Scripting (XSS).
- Unpinned versions can cause silent updates that might break the site layout or introduce unforeseen behavior.

🛡️ **Solution:**
- Hardcoded a specific version (`3.4.5`) in the CDN URL to guarantee stability.
- Appended the appropriate Subresource Integrity (SRI) hash and the `crossorigin` attribute to ensure that the browser blocks the execution of the script if its content is altered on the CDN or intercepted during transport.
